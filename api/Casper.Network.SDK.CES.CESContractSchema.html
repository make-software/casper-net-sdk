LoadAsync(ICasperClient, string, uint?)

Fetches and parses the CES event schema for a contract from the Casper network.

Declaration
public static Task<CESContractSchema> LoadAsync(ICasperClient client, string contractPackageHash, uint? version = null)
Parameters
Type Name Description
ICasperClient client

An active ICasperClient instance.
string contractPackageHash

Either a contract hash (prefix "contract-") or a contract-package hash (e.g. "hash-abc…def" or "package-abc…def").
uint? version

The contract version number to load when a package hash is supplied. Pass null (the default) to load the latest active version. Ignored when a direct contract hash is provided.
Returns
Type Description
Task<CESContractSchema>

A fully-populated CESContractSchema with ContractHash and ContractPackageHash set. When a direct contract hash is supplied, ContractPackageHash is null.
Remarks

The contractPackageHash parameter accepts either a contract hash or a contract-package hash:

  • If the value starts with "contract-" (e.g. "contract-dead…beef") it is treated as a direct contract hash and the package-resolution step is skipped. The version parameter is ignored in this case.
  • Otherwise it is treated as a contract-package hash (e.g. "hash-abc…def" or "package-abc…def") and the method enumerates the package to resolve the target contract version: when version is provided that exact version is selected; when version is null (the default) the highest-numbered active (non-disabled) version is used.

After resolving the contract the method fetches its named-key list to locate the __events_schema and __events URefs, then queries the schema CLValue directly from the __events_schema URef and parses it into a CESContractSchema. The resulting schema has ContractHash, ContractPackageHash, SchemaURef, and EventsURef automatically populated.

Both the legacy (ContractPackage) and the new Casper-2.x (Package / entity) contract models are supported.

Exceptions
Type Condition
ArgumentNullException

Thrown when client or contractPackageHash is null.
KeyNotFoundException

Thrown when a specific version was requested but not found in the package.
InvalidOperationException

Thrown when the package has no active versions, the RPC result is in an unexpected format, or the __events_schema named key is absent.
