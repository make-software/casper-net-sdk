Namespace Casper.Network.SDK.CES

Classes

CESContractSchema

Full schema for a CES-compliant contract, parsed from the __events_schema named key. Maps event names to their CESEventSchema.

CESEvent

A fully parsed CES event containing the event name, its typed fields, and, optionally, the execution-context metadata of the event.

CESEvent.NamedArgListConverter

CESEventSchema

Schema for a single named CES event type, listing its fields in order.

CESEventSchemaField

Defines one field in a CES event schema: its name and Casper type.

CESParser

Parses CES (Casper Event Standard) schema and event bytes produced by smart contracts following the make-software CES convention.

Contracts store their event schema in the named key __events_schema (a CLValue of type Any) and emit events into __events (a CLValue of type Map(U32, Bytes)).
